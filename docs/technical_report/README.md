# GomoNova 技术报告

## 这是什么

本技术报告详细解释了 GomoNova 五子棋 AI 的设计思路和实现原理。GomoNova 是一个完全从零训练的五子棋 AI——不使用任何人类棋谱，不借用任何已有模型，仅通过自我对弈和强化学习从游戏规则中习得下棋能力。

## 适用读者

- 熟悉 Python 基本语法
- 了解神经网络的基本概念（层、权重、前向传播、反向传播）
- 刚接触 PyTorch 或类似深度学习框架
- 对强化学习有初步兴趣（无需先验知识）

## 前置知识

| 需要 | 不需要 |
|------|--------|
| Python 基础（类、函数、列表） | 五子棋高手水平 |
| 知道什么是卷积神经网络 | 强化学习数学推导 |
| 了解 tensor（多维数组）的概念 | 分布式训练经验 |
| 基本的线性代数直觉（矩阵乘法） | CUDA 编程 |

## 如何对照代码阅读

每章会引用具体的源文件路径。建议：

```bash
# 克隆项目
git clone https://github.com/goooxu/GomoNova.git
cd GomoNova

# 安装依赖（用于运行示例）
pip install torch numpy pyyaml rich click

# 运行测试验证环境
python -m pytest tests/ -v
```

阅读时打开对应的源文件，对照报告中的代码片段理解实现。
