# GomoNova 技术报告

## 这是什么

本技术报告详细解释了 GomoNova 五子棋 AI 的设计思路与完整实现。GomoNova 是一个**完全从零训练**的五子棋（连珠规则）AI——不使用任何人类棋谱，不借用任何已有模型结构，不加载任何预训练权重，仅凭游戏规则通过自我对弈习得下棋能力。

与"训练时也用不上搜索"的朴素方案不同，GomoNova 在**训练阶段**引入了蒙特卡洛树搜索（MCTS）来生成高质量的学习目标，但在**对战阶段**完全依靠神经网络的一次前向推理落子，不做任何搜索。这套"训练用搜索、对战纯推理"的思路正是 AlphaZero 的核心思想，本报告会用最直白的语言把它讲清楚。

## 适用读者

- 熟悉 Python 基本语法（类、函数、列表推导）
- 了解神经网络的基本概念（层、权重、前向传播、反向传播）
- 刚接触 PyTorch 或类似深度学习框架
- **没有强化学习背景**——本报告会从零讲清自博弈、MCTS、策略/价值等概念

## 如何对照代码阅读

每章开头会列出涉及的源文件路径，正文中的代码片段均取自真实源码（为便于理解可能略有精简）。建议：

```bash
# 进入项目目录
cd gomonova

# 安装依赖
pip install torch numpy pyyaml rich click fastapi uvicorn

# 运行测试验证环境
python -m pytest tests/ -v
```

阅读时打开对应源文件，对照报告中的代码片段理解实现。每章末尾的「动手实验」都是可直接运行的代码，强烈建议亲手跑一遍。

## 项目快照

| 指标 | 数值 |
|------|------|
| 网络参数量 | 62.7M（192 通道 / 10 个 MSAR 块） |
| 输入编码 | 16 通道（含最近 6 手历史） |
| 训练迭代 | 3000 轮 |
| 训练损失 | 5.97 → 2.09 |
| 训练硬件 | 4× GPU（DDP 并行） |
| 对战方式 | 纯神经网络前向推理（无搜索） |
